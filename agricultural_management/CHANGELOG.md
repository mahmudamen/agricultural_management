# Changelog

All notable changes to the Agricultural Management module will be documented in this file.

## [18.0.1.0.0] - 2026-03-19

### Initial Odoo 18 Release

#### Added
- Farm & Location Management with 4-level hierarchy (Farm/Sector/Unit/House)
- Crop Management with lifecycle tracking and yield analytics
- Harvest Scheduling with Gantt chart visualization
- Harvest Sorting & Grading with batch processing
- Production Requests with multi-level approval workflow
- Production Request Templates for recurring operations
- Cost Allocation with analytic account integration
- Section-based Operations Dashboard (12 section types)
- Agricultural Projects with budget and cost/profit tracking
- Household Harvest tracking
- Stock Production Lot management with agricultural extensions
- Multi-warehouse integration (Raw Materials, Finished Goods, Pre-Sale)
- Full accounting integration with automated journal entries
- Purchasing integration with RFQ management
- Worker management and task assignment
- Email notification system for task alerts
- Role-based security (Manager/User/Readonly groups)
- Mobile responsive interface
- Arabic RTL support with full translation (ar.po)
- Demo data for easy evaluation
- Professional Odoo Apps store listing

#### Technical
- 19 models with comprehensive business logic
- OWL-based kanban and dashboard components
- Gantt chart scheduling view
- Custom SCSS theming for farm dashboard
- Sequence-based automatic numbering
- Mail thread integration on all major models
