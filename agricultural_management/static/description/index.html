Key Features

  • OWL Dashboard with Chart.js — 8 KPI cards, 3 interactive charts (Revenue vs Cost, Cost Breakdown doughnut, Yield Efficiency line), live RPC data, dark/light mode, responsive design
  • 4-Level Farm Hierarchy (Farm → Sector → Unit → House) with dynamic Total Area calculation including all children, supporting Meter and Feddan measurements
  • Real-Time Costing Engine — materials, labor, equipment costs flow through analytic accounts per farm for instant cost-per-crop, per-house, per-season analysis
  • 7-Step Production Request Workflow with multi-level approval (Draft → Submitted → Dr. Approved → Inventory Review → Transfer Ready → RFQ Pending → Completed)
  • Harvest Scheduling with quality-based sorting (Grade A/B/C), batch lot generation, waste tracking, grade-based pricing, and automatic stock pickings
  • Full Accounting Integration — automated journal entries, multi-journal setup, budget variance analysis, analytic accounts auto-created per farm, cost allocation with percentage distribution
  • Multi-Warehouse Stock Management with auto-created locations per farm, internal transfers, lot traceability, perpetual inventory valuation
  • 12-Section Operations Dashboard (Production, Cost Centers, Accounting, Finished Goods, Sorting, Warehouses, Workers, Pre-Sale, Purchasing, Harvest, Vehicles, Maintenance)
  • Role-Based Security visible in User Settings — Agricultural Role (User/Engineer/Manager) + department checkboxes (Warehouse, Purchase, Accountant, Section Manager)
  • Sales & Purchasing integration with vendor evaluation, auto-RFQ from production requests, grade-based customer invoicing, and waste cost handling
